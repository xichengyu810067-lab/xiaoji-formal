AI 與聊天

  • @小吉聊天一般成員被提及時提供一般對話、簡單回覆與可安全降級的 AI 回應。
    如何使用
    @小吉 後輸入想聊的內容。
    使用限制
    一般使用者可用。只 @小吉 時回「我在，有什麼事嗎？」（每人 10 分鐘一次）。沒有文字、10 分鐘內第 3 次說相同的話、同一伺服器 60 秒超過 5 次或 10 分鐘超過 20 次、同一頻道 60 秒合計超過 10 次的訊息不會回覆；10 分鐘內被擋 3 次會暫停 AI 對話 10 分鐘，再犯延長為 30 分鐘、2 小時。伺服器的 AI 額度用完時，小吉會請你晚點再試。
  • 個人化對話風格一般成員查看或保存自己的對話風格。
    如何使用
    使用 /chat-style current 或 /chat-style set。
    使用限制
    一般使用者可用；偏好依使用者帳號保存。
  • 情侶模式一般成員明確開啟、關閉或查看親暱文字語氣。
    如何使用
    使用 /romance start、/romance stop 或 /romance status。
    使用限制
    一般使用者可用，且必須由本人明確選擇開啟。
  • 聊天記憶一般成員記住你說過的喜好與在伺服器裡聊過的內容，讓小吉記得剛剛聊了什麼、知道你是誰。
    如何使用
    第一次聊天時選擇是否公開；用 /memory 查看、補充、刪除或停止記憶。
    使用限制
    私訊不會被記住；每人每天最多記 30 則，每月 1 號中午 12:00 重新計算並刪除上個月的內容；其他成員不能查詢你的記憶。
  • 好奇寶寶 /student一般成員小吉開一個討論串問你問題，接著你的回答繼續問。
    如何使用
    使用 /student 開始，用文字或圖片回答。
    使用限制
    每一輪最多 3 題；10 分鐘沒回答就結束。
  • 看圖一般成員聊天時附上圖片，小吉可以描述與討論圖片內容。
    如何使用
    @小吉、叫小吉或回覆小吉時附上圖片。
    使用限制
    每則最多 3 張、每張 5MB 以內（png、jpg、gif、webp）；不辨識照片中的人、不讀出個人資料；每張圖另算 10 次伺服器 AI 額度。
  • 上網搜尋一般成員問到新聞、比賽結果等即時資訊時，小吉會自己上網查。
    如何使用
    直接問小吉即可。
    使用限制
    引用時只寫網站名稱；搜尋結果可能過時或有誤；每次搜尋另算 1 次伺服器 AI 額度。

實用工具

  • 美食地圖一般成員查食譜、請小吉推薦某個地區的美食，或把推薦的店加入伺服器自己的美食地圖。
    如何使用
    使用 /food recipe、/food nearby、/food add、/food list 或 /food remove。
    使用限制
    食譜與附近美食由 AI 產生，每次另算 1 次伺服器 AI 額度，資訊可能有誤或過時；推薦只列店名與地址，請自行在地圖 App 搜尋；伺服器美食地圖（/food add、list、remove）目前是測試中的功能，只有授權的伺服器可以使用，每個伺服器最多 300 家店。
  • 股票報價一般成員查詢台股（上市、上櫃）、台灣與美國 ETF、美股與加密貨幣的報價、近一個月走勢圖，並保存自己的自選股清單。
    如何使用
    使用 /stock quote、/stock chart、/stock watchlist、/stock watch-add 或 /stock watch-remove；聊天時直接問小吉「台積電現在多少」也可以。
    使用限制
    報價可能延遲，僅供參考，不構成投資建議；美股與加密貨幣查詢有次數上限；自選股每人最多 10 檔。
  • 天氣查詢一般成員查詢指定地點或自然語言的天氣問題。
    如何使用
    使用 /weather，或向小吉詢問天氣。
    使用限制
    一般使用者可用；即時查詢需要已設定天氣服務。
  • 跨伺服器個人提醒一般成員新增、列出與刪除自己的提醒，並在重啟後恢復排程。
    如何使用
    使用 /remind add、/remind list 或 /remind delete。
    使用限制
    提醒會發送到建立時的伺服器文字頻道；本人可跨伺服器管理自己的提醒，不能管理他人的提醒。
  • 個人全域行事曆一般成員建立只有自己可查詢的個人事件，並在可使用小吉的不同伺服器共用。
    如何使用
    使用 /calendar add 新增、/calendar list 查詢、/calendar delete 刪除自己的事件。
    使用限制
    事件依 Discord 帳號隔離；管理員與機器人擁有者也不能跨讀或刪除他人的事件。所有回覆只有本人可見，操作需在伺服器文字頻道內進行。
  • 抽籤與擲骰一般成員抽取一則小吉籤，或擲出骰子與總和。
    如何使用
    使用 /fortune 或 /roll。
    使用限制
    骰子面數可設為 2–1000 面，數量可設為 1–20 顆。

吉幣、工作與銀行

  • 吉幣與台灣每日簽到一般成員查看跨伺服器帳號餘額、簽到、排行榜與經濟摘要。
    如何使用
    使用 /coins、/daily，或用 /leaderboard 選擇吉幣餘額或總資產排行榜。
    使用限制
    每日簽到依台灣日期計算；每位玩家一天一次，於可使用小吉的伺服器間共用。一般使用者可查詢自己的餘額與公開排行榜；總資產排行榜固定顯示前 25 名。涉及他人帳務或設定的操作仍需適當權限。
  • 全域商店與背包一般成員瀏覽普通或精品商品、購買商品，並查看自己的背包與購買紀錄。
    如何使用
    使用 /shop list、/shop buy、/shop purchases、/inventory，或 /luxury list、/luxury buy、/luxury inventory、/luxury history。
    使用限制
    普通與精品商品、庫存、限購與背包在可使用小吉的伺服器間共用；購買紀錄會保留來源伺服器。新商品不能附 Discord 身分組；商品上架與調整僅限小吉擁有者。
  • 銀行與定存一般成員查看跨伺服器帳號的錢包、活存、定存與利率，並進行存提款及到期處理。
    如何使用
    使用 /bank balance、/bank deposit、/bank withdraw、/bank interest、/bank rate-list 或各項 fixed 子命令。
    使用限制
    帳務與利率依帳號全域共用，但操作仍受目前伺服器的吉幣功能狀態限制；一般使用者可查看自己的帳務與目前利率。查看他人或全體帳務與查閱利率調整紀錄，僅限小吉擁有者或 Administrator；設定利率僅限小吉擁有者。
  • 工作系統一般成員查看職業、選擇下一期唯一全域主職、提交產出、查看薪資與提出扣薪申訴。
    如何使用
    使用 /work list、/work start、/work status、/work submit、/work payroll 或 /work appeal。
    使用限制
    每個帳號同一時間只有一個全域主職；目前不開放辭職，工作會在選定的天數期滿後自動結算。部分任務流程受伺服器權限與工作條件限制。
  • 小吉農場與廚房一般成員經營跨伺服器共用的個人農場：買種子播種、澆水、收成並出售作物，再用作物下廚做料理。
    如何使用
    使用 /farm view 打開農場面板（也可從 /board start 選「小吉農場」），/farm plant 播種、/farm shop 查看價格與規則；下廚使用 /kitchen cook、/kitchen recipes、/kitchen eat、/kitchen gift 或 /kitchen sell。
    使用限制
    作物與料理每人每天（台灣日期）合計最多賣 500 吉幣。作物超過 14 天沒澆水會枯死並休耕 14 天；化肥每格最多 5 包，用滿後下一次收割那格地就荒廢，需花吉幣重新開墾。料理吃掉只加成農場本身；每天最多送出 5 道，收到的料理只能吃、不能賣或再送。
  • 籌碼兌換一般成員查看帳號的吉幣與籌碼餘額，並進行兌換與查閱流水。
    如何使用
    使用 /exchange balance、/exchange buy-chips、/exchange cashout 或 /exchange history。
    使用限制
    帳號資料在可使用小吉的伺服器間共用；交易仍需符合帳務與場館條件。

棋盤與推理遊戲

  • 開局與共通限制一般成員在同一文字頻道建立、加入與進行一局棋盤或推理遊戲。
    如何使用
    建立者使用 /board start 選擇遊戲，其他人使用 /board join；建立者按遊戲訊息的開始按鈕後進行。使用 /board status 查看進度。
    使用限制
    每個頻道同時只能有一局。等候超過 10 分鐘，或進行中超過 24 小時沒有有效走棋或判題進展時，遊戲會結束；查看或重新整理不延長時間。沒有電腦對手、投注或新的吉幣獎勵。
  • 五子棋一般成員兩位玩家在 15×15 棋盤輪流落子，連成至少五子獲勝。
    如何使用
    建立者使用 /board start 選擇五子棋；輪到自己時按落子按鈕並在座標視窗輸入位置。
    使用限制
    自由連線規則下超過五子同樣算勝。開始後使用 /board leave 視為認輸或退賽。
  • 西洋棋一般成員兩位玩家依標準西洋棋規則對弈。
    如何使用
    建立者使用 /board start 選擇西洋棋；以走棋按鈕的座標視窗選擇起點、終點，必要時選擇升變。
    使用限制
    支援王車易位、吃過路兵與兵升變。三次同局面或 50 步可主張和棋；五次同局面或 75 步自動和棋；將死優先。開始後使用 /board leave 視為認輸或退賽。
  • 圍棋一般成員兩位玩家在 9×9 棋盤輪流落子，採中國面積計分，白方貼目 7.5。
    如何使用
    建立者使用 /board start 選擇圍棋；按落子按鈕輸入座標。雙方都停一手後，依提示標記並確認死子。
    使用限制
    不能自殺落子或造成重複局面。雙方共同確認完整死子群才計分；有歧見時可恢復對弈。開始後使用 /board leave 視為認輸或退賽。
  • 六角星跳棋一般成員支援 2、3、4 或 6 人；每位玩家有 10 顆棋子，最先全部移入目標營地者獲勝。
    如何使用
    建立者使用 /board start 選擇六角星跳棋；按移動／連跳按鈕，依序輸入棋盤圖上標示的點位名稱（例如 E5 F5，連跳要寫出每個落點）。面板會列出每位玩家的棋色與出發、目標位置。
    使用限制
    連跳不可只填起點與終點；多人局請等待自己的回合。開始後使用 /board leave 視為認輸或退賽。
  • 象棋一般成員兩位玩家在 9×10 棋盤依象棋走法對弈。
    如何使用
    建立者使用 /board start 選擇象棋；以走棋按鈕的座標視窗選擇起點與終點。
    使用限制
    將帥不得照面；馬受蹩馬腿限制、象不能過河，砲吃子時須隔一子。相同局面第三次出現即和棋；不提供競賽規則的長將、長捉裁判。開始後使用 /board leave 視為認輸或退賽。
  • 海龜湯一般成員1–20 人的多人問答推理遊戲，由小吉擔任主持與裁判。
    如何使用
    建立者使用 /board start 選擇海龜湯；參與者只可按遊戲訊息的提問或猜答案按鈕，並在開啟的輸入視窗輸入內容。
    使用限制
    不可直接在聊天訊息中提問或作答。無意義的提問、10 分鐘內第 3 次問相同的問題，或同一人 60 秒超過 6 次、10 分鐘超過 40 次的提問不會判題，只回給本人看的說明，棋局保留。只有本局結束後，曾參與該局的玩家才能查看答案；開始後只有建立者可使用 /board stop 結束海龜湯。
  • 狼人殺一般成員6–12 人的陣營推理遊戲，由小吉擔任法官主持；依人數自動分配狼人、預言家、女巫、獵人、守衛與平民。
    如何使用
    建立者使用 /board start 選擇狼人殺，並可在等候室按鈕調整節奏、勝利條件（屠邊或屠城）、出局是否公開身分與角色數量。開始後在面板下方的討論串討論；按「查看身分」看自己的角色，夜晚技能、投票與獵人開槍都按「行動」。
    使用限制
    身分、夜晚結果與查驗結果只用只有本人看得到的回覆告知。存活玩家連續兩次該行動或投票時沒有回應，會被判定離席出局；使用 /board leave 立即出局。房主可使用 /board stop 結束（記為平手）。沒有吉幣獎勵。
