# 全域經濟 v21 整合契約

## 權威範圍

- 吉幣錢包、每日簽到、一般債務、一般商店與精品商店皆以 Discord 使用者 ID 為全域權威鍵。
- 伺服器 ID 只保留為交易、建立來源與稽核資訊；不再切分商品、庫存、限購或簽到狀態。
- 一般商品 ID 為 `g_` 開頭字串；精品商品 ID 為 `l_` 開頭字串。舊整數 ID 不可用於新版公開流程。
- 新一般商品不可建立或綁定 Discord 身分組；購買流程也不會授予身分組。

## 每日簽到

- 同一使用者每天只可在所有伺服器合計簽到一次，日期以台灣時間計算。
- v21 遷移會依使用者與日期去除舊跨群重複紀錄，保留排序後最早一筆，並依實際連續日期重算 streak。
- 重複簽到固定回覆下一個台灣時間午夜，不使用相對倒數。

## 一般債務

- 可抵債收入採明確允許清單：簽到、工作薪資、基本薪資、系統／活動獎勵、賭場遊戲收入與小費收入。
- 可抵債收入先扣一般債務，餘額才進入錢包或籌碼；交易 metadata 記錄 gross、offset、net 與抵債前後金額。
- 賭場只以派彩扣除本次下注後的新收益抵債；平手、退還下注與勝局返還的下注本金均不抵債。
- 退款、銀行本金／利息、籌碼兌回、借貸與其他未列入清單的正向入帳不抵一般債務。

## 服務端整合

- 商品 API 雖保留 `guildId` 參數供功能啟用與來源稽核使用，但商品查找、庫存、限購和使用者持有量皆為全域。
- 任何新增收入種類若應抵債，必須明確加入錢包或籌碼收入允許清單並補原子性測試；不可用「所有正數都抵債」的隱含規則。
- v21 只遷移每日簽到。新版不讀取舊分群商店與精品資料，也不會自動補入預設商品。
