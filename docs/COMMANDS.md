# 公開指令

公開指令以 global commands 部署；只有已通過小吉准入審核的伺服器能執行。

## 一般與個人化

- `/help`、`/ping`、`/status`、`/about`
- `/weather city`、`/poll`、`/remind`、`/calendar`
- `/set-welcome channel`：需 Manage Server，設定新人歡迎頻道。
- `/chat-style`、`/romance`

## 社群活動

- `/word-chain`、`/number-chain`
- `/daily-riddle`、`/daily-discussion`

活動設定沿用各指令既有的 Discord 權限檢查；它們不是私有伺服器管理模組。

## 吉幣、工作與遊戲

- `/coins`、`/daily`、`/leaderboard`、`/shop`、`/buy`、`/inventory`
- `/work`、`/bank`、`/exchange`
- `/casino-lobby`、`/duel-tower`、`/casino`、`/casino-venue`
- `/luxury`、`/pawn`、`/games`

具設定能力的子指令仍會檢查其既有 owner 或伺服器權限。工作資料可在所有已審核伺服器運作；額外 Discord role 副作用由可選擴充決定。
