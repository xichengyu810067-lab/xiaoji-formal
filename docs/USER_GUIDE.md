# 小吉使用指南

1. 在小吉所在的伺服器輸入 `/help` 查看公開指令。
2. 提及小吉即可聊天；可用 `/chat-style` 調整跨伺服器對話風格。
3. 可用 `/remind`、`/calendar`、`/weather` 與 `/poll` 處理日常需求。
4. `/set-welcome` 供具 Manage Server 權限者設定公開新人歡迎。
5. 吉幣、工作、社群活動與遊戲的操作方式可直接查看各 Slash Command 選項說明。
6. 想知道小吉在你的伺服器裡能做什麼、不能做什麼，以及邀請時該給哪些權限，見 [管理功能隔離說明](MANAGEMENT_ISOLATION.md)。

小吉不審核伺服器：加入任何伺服器後，公開功能都可以直接使用，不需要等待批准。

## 傳送與安全限制

- 新人歡迎、工作提醒與接龍反應等公開功能，在每個伺服器都會執行，不需要審核。剛升級或重新建立安全帳本時，建立前的歡迎、工作提醒與接龍反應不會補送。同一個人在同一個伺服器只會被歡迎一次：以小吉接受歡迎請求為準，被接受後因限流而沒有送出的也算一次，之後再加入不會再歡迎；更新之前已被歡迎過的人，第一次重新加入時還會被歡迎一次。
- 小吉送出的文字會移除未核准的連結；一般使用者輸入不會觸發 `@everyone`、`@here` 或身分組 ping。投票與提醒也適用這個規則。
- 和小吉的 AI 對話有防洗頻：沒有文字（只有表情符號或貼圖）、一直重複同一個字或同一句話、短時間連發（同一伺服器 60 秒超過 5 次、10 分鐘超過 20 次），或同一頻道太多人同時找小吉時，小吉不會回覆。10 分鐘內被擋 3 次，會在那個伺服器暫停 AI 對話一段時間（10 分鐘起，最長 2 小時）；只被擋一兩次不會暫停。只 @小吉 或只叫「小吉」（後面只有標點或表情符號也一樣）時，小吉會回「我在，有什麼事嗎？」（每人 10 分鐘一次）；直接回覆小吉、內容只有標點或表情符號時，小吉不回覆，也不算違規。
- 海龜湯的提問也有防洗頻：無意義的提問、10 分鐘內第 3 次問相同的問題，或 60 秒超過 6 次、10 分鐘超過 40 次的提問不會判題，只回給你自己看的說明，棋局保留。
- 短時間內大量送出時，部分工作可能延後。延後不代表已完成；小吉不會為了趕上進度而重複送出同一則受保護訊息。
- 若 `/status` 顯示新人歡迎或接龍維護中，表示對應的安全保護暫時不可用；其他公開功能仍可照常使用。請由伺服器管理員查看 Bot 的維運通知並處理。
