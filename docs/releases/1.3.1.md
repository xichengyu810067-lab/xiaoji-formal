# 小吉 1.3.1

這次小吉想答案時會先跟你說一聲、會記得頻道裡聊過的話，還多了股票、美食、農場、廚房、狼人殺和星火接續，官網也更好用了。

## 聊天

- 小吉想答案時會先回一則「小吉思考中…」，想好之後直接改成回答。
- 小吉會記住成員在伺服器頻道裡說過的話，聊天時能接上剛剛的話題。每人每天最多記 30 則，當天用完會先借用隔天的額度，當月額度用完就不再記；台北時間每月 1 號中午 12:00 重置額度，並刪除上個月的紀錄。私訊內容一律不記。
- 第一次在這一版跟小吉聊天時，小吉會再請你選一次記憶要不要公開：公開時，小吉所在的所有伺服器都會收錄並使用你的發言；不公開時，只在同一個伺服器內收錄和使用。用 /memory 可以查看用量、刪除自己的紀錄或改設定。
- 問「小吉你知道我是誰嗎？」時，小吉會依照你的記憶回答，不再說沒有記憶。
- 小吉認得自己的開發者，也會照開發者的需要協助寫程式。

## 新指令與遊戲

- /stock：查台股（上市、上櫃）、台灣與美國 ETF、美股與加密貨幣的報價和走勢圖，可以建立自選清單，也能在聊天時直接問小吉報價。台股資料來自證交所與櫃買中心，其他市場來自 Twelve Data。
- /food：查食譜、依地區和想吃的東西推薦附近美食。伺服器美食地圖（/food add、list、remove）是測試中的功能，只有授權的伺服器可以使用。
- /farm 與 /kitchen：種作物、收成、做料理、出售或送人；作物與料理每天合計最多賣 500 吉幣。
- 狼人殺：用 /board start 開局，小吉當法官。
- /spark-relay 星火接續：小吉隨機分組，每組領幾件小任務，每天輪一個人完成；錯過的任務可以在三天內補做，全組都有參與才發獎金。
- 文字接龍：字典裡查不到的詞，小吉會請 AI 判斷能不能接。

## 官網

- 新的「功能與指令」頁可以搜尋全部功能和指令，配色會跟著台北時間變化。
- 狀態頁會顯示每個功能實際是否正常（正常、異常、修復中等），資料由小吉每分鐘回報。
- 官網客服會先由 AI 回答問題，答不了時再引導寄信。
- 官網改用手寫字體（辰宇落雁體，只收官網用到的字），文字放大、筆畫加粗；首頁的區塊往上或往下捲動時都會播放淡入動畫。
- 使用者政策、隱私權政策與公開資料聲明改成各自的彈出視窗，每份都有編號目錄，捲動時會標出正在讀的段落；關閉視窗後仍停在原本的頁面。

## README

- README 換上新設計：會動的橫幅、對話示範動畫、各功能的小動畫圖示、兩欄目錄，標題改用跟官網一樣的手寫字，淺色與深色主題各有一套。
- 狀態徽章會即時顯示小吉現在是否正常運作。

## 政策更新

- 隱私權政策與服務條款更新為 1.3.1 版，2026 年 11 月 14 日生效，加入頻道記憶的收錄範圍、額度與刪除時間、記憶公開設定、開發者每週收到的記憶彙整、對話被阻擋時給開發者的通知（未開啟開發者模式時以加密方式保存），以及股票、美食與官網客服使用的外部服務。

## 升級

- 開啟對話封存的主機要改成 `XIAOJI_ARCHIVE_POLICY_VERSION=1.3.1`，否則封存會自動關閉。
- 股票的美股、ETF 與加密貨幣報價需要 `TWELVE_DATA_API_KEY`；沒有設定時只能查台股。
- 頻道記憶使用既有的 `TURSO_DATABASE_URL` 與 `TURSO_AUTH_TOKEN`；沒有設定時不會開啟。
- 狀態頁的功能狀態需要主機設定狀態回報的網址與簽章金鑰，Cloudflare Worker 要重新部署並套用 D1 migration `0002_support_usage.sql`；官網客服的 AI 回答需要在 Worker 設定 `ANTHROPIC_API_KEY`，沒有設定時官網會改用內建的常見問題。README 的狀態徽章讀的是重新部署後 Worker 新增的 `/api/public/badge`。
- 伺服器美食地圖只在 `XIAOJI_FOOD_MAP_GUILD_IDS` 列出的伺服器可用（逗號分隔），沒有設定時哪裡都不能用。
- 新指令 /stock、/food、/farm、/kitchen、/spark-relay 需要重新部署指令。
