# 小吉 1.2.1

這是 1.2.0 的修正版，只修一個問題，其他功能與資料都沒有變。

## 修正

- 開啟「AI 對話封存」之後，小吉在啟動前的檢查會找不到封存檔路徑的函式，導致無法啟動。現在已修正，開啟封存時可以正常啟動。沒有開啟封存的伺服器原本就不受影響。
- 新增一項測試，會在「封存開啟」的狀態下實際跑一次啟動前檢查，避免同樣的問題再發生。

## 升級

- 不需要改資料或設定。把程式換成 v1.2.1 後重新啟動即可。
- 對話封存是否開啟仍由擁有者決定；要開啟需要先設定 `XIAOJI_ARCHIVE_CAPTURE_ENABLED=true` 與 `XIAOJI_ARCHIVE_POLICY_VERSION=1.2.0`。
