# 小吉 1.3.4

這一版讓遊戲更好懂、海龜湯只要有 Claude 就能玩，也讓成員自己決定小吉怎麼稱呼自己。每日猜謎與每日議題改由 Claude 出題，狀態通知也不再一下異常、一下恢復。

## 稱呼

- 新增 `/memory nickname`：設定、查看或清除小吉稱呼你的名字（20 字以內）。小吉聊天時會用這個稱呼，而不是你的 Discord 名稱。
- 稱呼跟著你的記憶公開設定走：公開時所有伺服器共用一個，不公開時每個伺服器（以及私訊）各自一個。含連結、提及、符號標記或個人資料的名字會被拒絕；停止記憶時不能設定。

## 遊戲

- 西洋棋、圍棋、五子棋、象棋的面板會寫出每一方是誰、現在輪到誰；大廳會說明先加入的是哪一方。
- 六角星跳棋：
  - 大廳列出棋色分配與已加入的玩家，開始後每個座位寫出棋色、玩家，以及從哪個角落出發、目標是哪裡。
  - 棋盤圖放大，每個點與棋子上都印有名稱：字母是第幾列（由上而下 A～Q），數字是該列由左數第幾個點。走子直接輸入名稱，例如 `E5 F5`；連跳依序寫出每個落點，例如 `E5 G5 I5`。舊的 `q…r…` 寫法仍可使用。
- 棋局結束時，圖片底部用中文說明怎麼結束、哪一方獲勝，例如「對局已結束：將死，白方獲勝」。
- 海龜湯：
  - 只要設定了 `ANTHROPIC_API_KEY`，裁判就用 Claude 判定（和聊天相同）；沒有設定時才改用 Groq 或 OpenAI。判定結果仍只會是固定的幾種，並維持原本的次數與防洗版限制。
  - 猜錯時回「未答對，再想想看！」；問題與湯底矛盾時回「否」，只有線索真的沒提到時才回「無法判定」。
  - 長的湯面在圖片上自動換行，完整顯示。猜中後的按鈕改為「查看湯底」。
- 星火接續的報名卡片說明分組方式：大多每組 4～6 人，只有 2～3 人報名時就分成一組。

## 每日活動

- 有設定 Claude 時，每日猜謎與每日議題每天由 Claude 出一題，所有伺服器共用；題目會先檢查長度、格式、不和近 60 天重複、謎底不會被題目說破，不合格就重出，連續失敗才用內建題庫。
- 出題只送日期與近期題目，不含任何成員或伺服器資料，也不計入伺服器的 AI 額度。

## 吉幣

- `/leaderboard` 在成員很多的伺服器不再逾時：查詢名單前會先回應 Discord。

## 狀態與通知

- 服務要連續失敗至少 5 分鐘、期間沒有任何成功，才會被判定為異常；狀態通知要連續確認幾次才送出，短暫的問題不會再收到「異常」又「恢復正常」的私訊。
- 擁有者可以把小吉自己無法完成的發布公告失敗紀錄結案，狀態會立即重新計算。
- 擁有者回覆「解密」或「解碼」即可查看被擋下的回覆通知內容。

## 其他

- 指令實測截圖：1.3.4 測過的公開指令畫面整理在 [`docs/COMMAND_SCREENSHOTS.md`](../COMMAND_SCREENSHOTS.md)，成員名稱、頭像與伺服器資訊都已去識別化。
- 隱私權政策與使用者政策更新到 1.3.4：補上海龜湯裁判、`/memory nickname`、每日 AI 出題的說明，以及 AI 判定可能出錯的提醒。
- 啟動器可以用 `--retained-data-root=<資料夾>` 指定保留資料的位置，伺服器設定、投票、提醒、行事曆與歡迎／離開紀錄存在該資料夾，部署新版時不必再手動複製；沒有指定時行為不變。

## 升級

- 開啟對話封存的主機要改成 `XIAOJI_ARCHIVE_POLICY_VERSION=1.3.4`，否則封存會自動關閉。
- 海龜湯裁判使用既有的 `ANTHROPIC_API_KEY`，不需要另外設定 `GROQ_API_KEY` 或 `OPENAI_API_KEY`。
- 新增了 `/memory nickname`，部署後要重新部署指令。
- 啟動器第一次帶 `--retained-data-root` 啟動時，會從這一版的 `src/data` 建立保留資料資料夾；因此第一次部署這一版時，請照以往把資料檔放進新版的 `src/data`，之後的部署就不用再複製。
- 狀態頁的 Cloudflare Worker（官網客服的知識與指令清單）有更新，部署後要重新部署 Worker。
