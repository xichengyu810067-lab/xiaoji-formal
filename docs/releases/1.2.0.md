# 小吉 1.2.0

本版把擁有者的安全警示擴到所有伺服器、加強各伺服器之間的資料隔離、新增輸入端的釣魚與惡意連結偵測，並加入可選、預設關閉的外部第二意見（Jev）。

## 安全警示

- 任何伺服器出現常規的資安違規時，擁有者會收到固定格式的私訊：`【伺服器名稱】小吉遭受攻擊(類別)`。內容只有伺服器名稱與類別，不含成員的文字、帳號或任何 ID，也不經過 AI。
- 類別共八種：提示詞注入、套取開發資訊、索取個資或跨群資料、洗版、輸出護欄觸發、出口護欄阻擋、權限被拒、釣魚或惡意連結。
- 同一個伺服器、同一個類別：第一次偵測立刻私訊；之後一小時內只累計次數，一小時後的下一則會附上「（過去一小時共 N 次）」。合併窗存在安全帳本裡，重啟後一小時內也不會重複私訊。
- 安全警示有獨立的預算（每分鐘 3 則、每小時 20 則、每天 60 則），不占用也不被新伺服器加入、成員退出、恢復營運與帳本事件的預算占用。60 位成員同時對同一個伺服器發出注入句，擁有者只會收到 1 則私訊。
- 洗版只在頻道洪水或成員被冷卻時通知；單次無意義訊息、一次重複與單獨叫「小吉」不通知。權限被拒與管理員查詢非成員會通知。
- 原本被拒答的 AI 請求與被擋下的對外請求各自私訊「固定代碼」的做法已移除，只留在 log；被拒答請求「每人每天私訊一次」的上限也一併移除。
- 啟動保護或停運期間被丟棄的警示不補送；重啟後「N 次」的計數歸零。
- 新增輸入端的釣魚與惡意連結偵測：不連網，檢查仿冒網域、網址裡的帳密手法、IP 位址、仿冒品牌網域、誘餌用語加上非官方連結、短網址、直接下載可執行檔、`@everyone` 加上非官方連結。偵測到時只通知擁有者，**不刪除訊息、不禁言、不回覆**。

## 伺服器之間的資料隔離

- `/coins` 不再能查別人：所有人（包含管理員）只能看自己的吉幣資料。
- 管理員用 `/work status-user`、`/work status-all`、`/economy user`、`/economy audit work` 查別人時，成員在其他伺服器選擇的全域主職，以及該主職在其他伺服器領的薪水，一律不顯示。
- 新增擁有者專用的吉幣查詢功能：純讀、分頁、只有擁有者能執行，只在擁有者伺服器提供。
- 管理功能隔離：擁有者專用的資料庫管理功能（吉幣資料庫、商店與賭場管理、伺服器 AI 額度）移入私有擴充，公開程式碼不再含任何擁有者專用指令；公開指令與資料不變。說明見 `docs/MANAGEMENT_ISOLATION.md`。
- 管理員工具 `/bank balance-user`、`/economy user`、`/economy audit` 仍會顯示**同一個伺服器內成員**的全域錢包餘額（吉幣帳戶是跨伺服器共用的）。

## 可選：Jev 第二意見（預設關閉）

- 可選地把輸出端「被軟規則誤擋」的正當回覆交給 TypeSafe 的 Jev 模型做第二意見。**只能放寬兩條通用詞軟規則**；硬規則（密鑰、系統提示、環境檔、內部路徑、模型與供應商等）永遠照常，Jev 判斷失敗、逾時或停用時行為與以前完全相同。
- 需要同時設定 `JEV_MODE`、`JEV_API_KEY`、`JEV_GUILD_IDS`（白名單）與 `JEV_POLICY_ACK=yes`；連結風險的第二意見另需 `JEV_LINK_RISK=yes`。開啟後成員的文字（已去識別化）會送到 TypeSafe（託管於美國），請先更新隱私政策。
- 附離線評估工具與完整教學：`docs/JEV_SETUP.md`。

## 每日議題與猜謎

- `/daily-discussion run-now` 在排程已先發布時，會回「今日議題已發布（排程已先處理）」，不再誤報「發布 0」。
- 到點自動發布因計時器必然略晚於整點，以前幾乎一定被標成「比預定時間晚」；現在整點後 2 分鐘內發布仍算準時。補發規則不變。
- 管理紀錄的送出函式在沒有設定紀錄頻道時，如實回報沒有送出。

## 其他

- `/weather` 的第三方天氣文字不再觸發輸出護欄警示。
- 修正私有擴充中一個指令的選項順序（必填選項要排在選填之前），否則 Discord 會拒收整份伺服器指令清單。

## 升級注意

- 部署指令（`npm run deploy`）以更新 `/coins` 的說明；擁有者伺服器的指令改由私有擴充一併部署，請在載入私有擴充的環境執行。
- 沒有新的必要環境變數；Jev 相關設定全部可選。
- 隱私政策與服務條款改為 1.2.0 版：不再寫「審核」，並新增安全警示、全體吉幣查詢與選用外部服務的說明。生效日期在部署當天才填入：改 `website/policyPublication.js` 的 `effectiveDate`，再執行 `node scripts/render-policy-publication.js`。
- 程式內的對話封存政策版本（`ARCHIVE_POLICY_VERSION`）同步改為 `1.2.0`。**部署時主機的 `.env` 必須同步設定 `XIAOJI_ARCHIVE_POLICY_VERSION=1.2.0`，否則 AI 對話封存會自動關閉**（版本不一致時封存不會寫入，也不會報錯）。
- 行為變更清單：`/coins` 只查自己；管理員查他人時不顯示他群主職與發薪；擁有者私訊改為固定格式的安全警示，舊的固定代碼私訊與每人每天一次上限移除。
