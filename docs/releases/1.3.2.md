# 小吉 1.3.2

這一版修好狀態頁顯示錯誤的功能，狀態頁也能看到每一個指令的狀態。

## 狀態頁

- 狀態頁現在會列出每一個公開指令和子指令的狀態，可以搜尋，也能依分類收合。
- 小吉沒有回報即時資料時，狀態頁會改為顯示這一版發布前的離線健檢結果，並標明是哪一版、什麼時候檢查的。
- 數字接龍和文字接龍：以前只要有一次 ✅ 反應送不出去，狀態就會一直停在「異常」；現在只要之後的反應成功送出，就會自動恢復正常。
- 俄羅斯方塊、數字配對、數獨在 Discord 用 /board 玩，狀態頁改看 /board 本身，不再一直顯示「維護中」。

## 其他

- 更新連線套件 undici 到 6.29.1，修正 TLS 憑證驗證與阻斷服務相關的已知漏洞（discord.js 透過它連線 Discord）。
- 開發者新增一套在本機執行的健檢，發版前會檢查所有指令、程式安全與架構，不使用 GitHub Actions 額度。

## 升級

- 隱私權政策與服務條款沿用 1.3.1，`XIAOJI_ARCHIVE_POLICY_VERSION` 維持 `1.3.1`。
- 狀態快照新增各指令的狀態欄位：**狀態頁的 Cloudflare Worker 必須先更新**，再更新小吉主機；順序相反時，舊版 Worker 會拒收新格式的快照。Worker 連接 GitHub 自動部署時，xiaoji-formal 的 main 更新後就會先部署。
- 這一版沒有新增或修改指令，不需要重新部署指令。
